## Intent

Promo de 10 segundos para Gestión Urbana (https://frontend-ebon-six-27.vercel.app/), plataforma chilena de gestión inmobiliaria. Tono seguro, cercano y moderno. Vende el producto (sell, no tour completo): hero con propuesta de valor, prueba con catálogo real y stats, cierre con CTA. Sin narración larga — kinetic type + capturas reales del sitio + CTA final. Duración total 10s.

## Assets

- capture/screenshots/full-page.png — plate de página completa para scroll/pan del hero (base visual real del sitio).
- capture/assets — fotos reales de propiedades (departamento Av. Italia, casa Las Condes, oficina El Golf) + hero slides para prueba social.

## Customizations

- Captura real del sitio como base visual (show-it dentro de promo sell).
- Kinetic type en español con números de prueba: 120+ propiedades, 98% satisfacción, 48h respuesta.
- Cierre con CTA "Ver Propiedades" + marca Gestión Urbana.
